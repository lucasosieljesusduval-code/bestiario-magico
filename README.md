# bestiario-magico
Bestiário de um universo autoral, desenvolvido com HTML, CSS e JavaScript.
# Bestiário Mágico

Meu primeiro projeto de portfólio, desenvolvido enquanto
aprendo HTML, CSS e JavaScript.

Inspirado na organização de wikis, o site apresenta criaturas
de um universo autoral, com informações sobre seus habitats,
hábitos e habilidades.

## Acesse o site

[Visitar o Bestiário Mágico](https://lucasosieljesusduval-code.github.io/bestiario-magico/)

## Tecnologias utilizadas

- HTML para estruturar o conteúdo.
- CSS para estilização e adaptação a diferentes telas.
- JavaScript para controlar o carrossel.

## Recursos

- Carrossel com imagens, nomes e descrições dinâmicos.
- Imagens do carrossel com links para as fichas.
- Menus com subcategorias.
- Fichas do Coelho Voador, Urso-Cipó e Peixe Terrestre.
- Formulário demonstrativo com seleção de reino e poder.

O formulário não envia nem armazena mensagens.
As demais categorias estão indicadas como conteúdo futuro.

## O que aprendi

- Organizar páginas com HTML semântico.
- Conectar páginas e seções por links.
- Usar classes, identificadores, Flexbox e estados de interação.
- Atualizar elementos da página com JavaScript.
- Publicar e atualizar um site com GitHub Pages.

## Como executar localmente

Baixe o projeto, extraia os arquivos e abra o index.html
no navegador, mantendo a organização das pastas.
